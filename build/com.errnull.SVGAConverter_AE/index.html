?PNG（兼容优先）：体积最大，但所有 SVGA 播放器都能读。
WebP 无损：再小 20%~35%，画质无损。
WebP 有损 q80：渐变/光效类素材可再降 40%~60%，文字描边可能出现轻微振铃。
注意：换格式只减体积，不降内存；iOS 13 及以下、部分老播放器不支持 WebP。 ?开：裁掉每张贴图的透明边、剔除全透明元素，安卓解码后的内存按裁后尺寸估算，通常明显下降。
弊端：导出更慢；被裁过的贴图不能再拿原尺寸图运行时替换——图层名含 avatar / nick / id 的会自动跳过（如 avatar1、nick 2、id3）。
关：保持原始导出行为。
